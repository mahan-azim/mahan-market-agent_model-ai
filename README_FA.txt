ماهان مارکت ایجنت — نسخهٔ معرفی پروژه

این بسته صفحهٔ معرفی واقعی پروژه است؛ API، ورود ChatGPT یا مدل فعال ندارد.
هدف: انتشار یک URL واقعی برای معرفی پروژه در فرم درخواست دسترسی.

انتشار مستقیم:
۱. فایل ZIP را Extract کن.
۲. وارد حساب Netlify شو و صفحه https://app.netlify.com/drop را باز کن.
۳. پوشه site را که index.html درون آن است، روی قسمت آپلود بکش.
۴. پس از انتشار، URL داده‌شده را باز کن و آن را در Website URL فرم وارد کن.
۵. برای به‌روزرسانی همین سایت، پوشه site جدید را در بخش Deploys همان پروژه بارگذاری کن.

برای این نسخه هیچ متغیر محیطی یا کلیدی لازم نیست.
کلید PROXY_API_KEY زمانی لازم می‌شود که بک‌اند واقعی اضافه شود.
مقدار کلید را در HTML، CSS، این README، GitHub یا پیام چت قرار نده.

آپلود مستقیم پوشه به معنی خصوصی‌ماندن HTML و CSS نیست؛ فایل‌های مرورگر عمومی‌اند.
برای بخش خصوصی باید Netlify Functions با فرایند deploy مناسب اضافه شود.
آپلود پوشهٔ استاتیک به‌تنهایی کد Functions را نمی‌سازد یا فعال نمی‌کند.
